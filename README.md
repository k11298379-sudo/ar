# AR-Опыт: «Волшебник Изумрудного Города»

Интерактивный сайт дополненной реальности (Web AR), работающий прямо в браузере смартфона (поверх живого видео с камеры) или на компьютере.

---

## 🚀 Быстрый запуск в 1 клик на любом ПК

Для запуска сервера просто дважды кликните по:
* **`start.bat`** (или `run.bat`)

Скрипт автоматически:
1. Запустит локальный HTTP (порт 8000) и защищённый HTTPS (порт 8443) сервер.
2. Определит ваш актуальный Wi-Fi адрес в домашней сети.
3. Выведет готовую ссылку и QR-код для подключения с телефона.
4. Откроет страницу на компьютере в браузере!

> **Требования к ПК:** Установленный Python 3 (при установке Python должна быть отмечена галочка *«Add Python to PATH»*). Никаких сторонних библиотек устанавливать не нужно — используются только встроенные модули.

---

## 📱 Как подключиться со смартфона (с камерой AR)

1. Компьютер и телефон должны быть подключены к **одному Wi-Fi роутеру**.
2. В браузере телефона откройте HTTPS-адрес, который покажет консоль, например:
   ```
   https://192.168.0.100:8443
   ```
   *(либо на компьютере нажмите кнопку 📱 вверху экрана и наведите камеру телефона на QR-код)*.
3. **Важно при первом открытии:**
   * Браузер покажет предупреждение о локальном сертификате («Подключение не защищено»):
     * **Android (Chrome):** нажмите **«Дополнительно»** ➔ **«Перейти на сайт (небезопасно)»**.
     * **iPhone (Safari):** нажмите **«Подробнее»** ➔ **«Посетить этот веб-сайт»** (подтвердите Face ID / пароль).
4. Нажмите большую зелёную кнопку **«Разрешить камеру 📸»** и подтвердите системный запрос браузера.
5. Включится камера вашего телефона — теперь вы в настоящем AR!

## 🖼️ Афиша фильма для сканирования и печати

Чтобы получить настоящий опыт оживающей афиши:
1. Откройте в браузере страницу афиши:
   ```
   http://localhost:8000/poster.html
   ```
   *(или нажмите кнопку `[ 🖼️ ]` в верхнем меню приложения)*.
2. Вы можете:
   * **Вывести её на экран** второго монитора, ноутбука или планшета (кнопка *«Во весь экран»*).
   * **Распечатать на принтере** на листе А4 (кнопка *«Распечатать афишу (A4)»*).
3. **Как оживить афишу:**
   * Отсканируйте камерой телефона QR-код прямо с этой афиши.
   * Наведите включённую камеру смартфона на постер — прямо из него в 3D вырвется ураган с домиком Элли!

## 🎬 Сценарий AR-опыта

1. **Сцена 1: Оживающая 3D-афиша, Ураган и Падение домика на Злую Ведьму**
   * В AR прямо поверх вашей комнаты/стола разворачивается 3D-диорама киноафиши:
     * **Афиша фильма** в золотой рамке «Волшебник Изумрудного Города».
     * **Сказочная зелёная поляна** с цветами, дорожкой и **кривым домиком Злой Ведьмы Гингемы**.
     * Из центра афиши ввысь вырывается **настоящий 3D-ураган**: 28 вихревых слоёв, более 1200 объёмных частиц бурана, спиральные ветровые ленты и летающие доски!
     * В потоках урагана кружится детальный **деревянный домик Элли** с трепещущими ставнями и верандой.
   * **Механика 3-х свайпов:**
     * **1-й свайп:** первый порыв ветра наклоняет воронку урагана, загорается 1-й кристалл `⚡`.
     * **2-й свайп:** сильный вихрь раскачивает бурю, ураган замедляется, загорается 2-й кристалл `⚡`.
     * **3-й свайп:** мощнейший ураганный порыв развеивает вихрь прочь! Домик Элли срывается и летит по высокой 3D-баллистической дуге прямо на **домик Злой Ведьмы**!
     * **Бабах!** Клубы пыли, домик ведьмы сминается, домик Элли пружинит при посадке, а из-под него эффектно выскальзывают **полосатые чулки со сверкающими серебряными башмачками** и золотыми искрами!

2. **Сцена 2: Изумрудный Город и шествие героев по Дороге**
   * Впереди вырастает сияющий Изумрудный Город.
   * Виртуальная камера **сама плавно оглядывается назад на 180°**.
   * Открывается Дорога из жёлтого кирпича: далеко на линии горизонта появляются крошечные фигурки друзей (**Элли, Тотошка, Страшила, Дровосек и Лев**) и начинают ритмично шагать по кирпичам, постепенно приближаясь к вам под звуки шагов.

3. **Сцена 3: Торжественный вход в Город**
   * Когда герои подходят вплотную, камера **сама плавно разворачивается обратно к Городу**.
   * Герои оказываются перед воротами замка и входят в изумрудный портал.

## 📁 Содержимое архива

* **`start.bat`** / **`run.bat`** — запуск сервера в 1 клик для Windows.
* **`server.py`** — сервер на Python (двойной HTTP/HTTPS с автоопределением IP и поддержкой SSL).
* **`index.html`** — полный клиентский код AR (Three.js 3D-диорама, 3D панорама, аудио-синтезатор, управление камерой).
* **`assets/three.min.js`** — локальная библиотека Three.js r128 (работает 100% автономно без интернета).
* **`cert.pem` / `key.pem`** — готовые локальные SSL-сертификаты для защищённого доступа к камере телефона по HTTPS.
* **`assets/`**:
  * `emerald_city.svg` — панорама Изумрудного Города.
  * `road.svg` — Дорога из жёлтого кирпича с перспективой.
  * `hero_*.svg` — векторные иллюстрации героев (Элли, Тотошка, Страшила, Дровосек, Лев).
